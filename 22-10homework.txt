----LLM in Technology (Artificial Intelligence)

LLM = Large Language Model

An LLM is a type of artificial intelligence model designed to understand and generate human-like language.

🔹 Examples:

GPT-5 (the model you’re talking to now)

ChatGPT

Google Gemini

Anthropic Claude

Meta LLaMA

🔹 How it works:

Trained on massive amounts of text data (books, websites, code, etc.)

Can answer questions, write essays, generate code, summarize text, translate languages, and more.

----What is cloud computing?
Cloud computing is the delivery of computing services (servers, storage, databases, networking, software, analytics, intelligence, etc.) over the internet (“the cloud”) instead of running them on your own physical hardware. Instead of buying and managing physical servers and data centers, you rent those resources from cloud providers and pay for what you use.

Types:
1.IaaS — Infrastructure as a Service
Raw compute, storage, networking. You manage OS, runtime and apps.
Example use: virtual machines, block storage, virtual networks.

2.PaaS — Platform as a Service
Managed platform for developing and running apps (databases, runtimes). You focus on code; provider manages OS and middleware.
Example use: app hosting, managed databases, CI/CD platforms.

3.SaaS — Software as a Service
Fully managed applications delivered over the web. Users just use the app; provider handles everything else.

Benefits:
Cost efficiency: pay only for usage; less capital expense
Scalability: handle traffic spikes without buying more servers
Speed & agility: provision resources in minutes
Global reach: deploy apps close to users worldwide
Managed services: less ops work for databases, ML, analytics
Innovation: access to cutting-edge tech (AI, big data tools)



----What is a Website?

A website is a collection of web pages connected under one domain name (like www.google.com) and accessible through the Internet using a browser.

Each website serves a purpose — for example, to share information, sell products, teach, or entertain.

--Main Features of a Website
 1. Basic Features

These are essential parts that every website should have:

Feature	Description
Domain Name	The website’s address on the internet (e.g., www.example.com).
Web Hosting	The server space where your website files are stored.
Homepage	The main entry page — it introduces the website and guides visitors.
Navigation Menu	Helps users move between pages (like Home, About, Contact).
Content / Pages	Text, images, or videos that provide information.
Responsive Design	The site looks good and works well on phones, tablets, and computers.
Footer	The bottom section with links, copyright info, and contacts.
 2. Functional Features

These make the website interactive and user-friendly.

Feature	Description
Contact Form	Lets users send messages or inquiries easily.
Search Bar	Allows users to find content quickly.
Login/Signup System	For user accounts, memberships, or dashboards.
Multimedia Support	Displays images, videos, animations, etc.
Social Media Integration	Links or embedded feeds from platforms like Instagram, LinkedIn, etc.
SEO (Search Engine Optimization)	Improves how easily the site can be found on Google.
Fast Loading Speed	Pages open quickly to keep users engaged.



----AWS S3 (Simple Storage Service)
🔹 What it is:

AWS S3 is a cloud storage service used to store and retrieve any amount of data (like files, images, videos, documents, backups, etc.) over the Internet.

🔹 In simple words:

It’s like Google Drive or Dropbox, but for developers and companies — more powerful, secure, and scalable.

🔹 Key Features:

Stores unlimited files (called objects) inside buckets.

Highly durable (your data is safe, stored in multiple locations).

Access anytime, anywhere using the Internet.

Used for: file storage, website hosting, backups, or data lakes.



----2. AWS Lambda
🔹 What it is:

AWS Lambda is a serverless computing service.
It lets you run your code without managing any servers — AWS handles everything.

🔹 In simple words:

You just write a function (small piece of code), upload it, and AWS runs it automatically when something happens (like a file upload or a button click).

You pay only for the time your code runs — not for idle servers.

🔹 Key Features:

Serverless: no need to manage servers.

Event-driven: runs when triggered (for example, when an image is uploaded to S3).

Supports multiple languages (Python, Node.js, Java, etc.).

Scales automatically.



----3. AWS Kinesis
🔹 What it is:

AWS Kinesis is a real-time data streaming service.
It collects, processes, and analyzes live data streams (like video, logs, or sensor data) instantly.

🔹 In simple words:

It’s used when data is coming continuously — not in files but as a stream, like a river of data flowing every second.

🔹 Key Features:

Handles real-time data (no delay).

Works with data from IoT devices, social media, logs, or apps.

Can connect with Lambda, S3, and databases for storage and processing.

Four main services under Kinesis:

Kinesis Data Streams – handles raw streaming data.

Kinesis Data Firehose – delivers data to destinations like S3 or Redshift.

Kinesis Data Analytics – analyzes streams in real time using SQL.

Kinesis Video Streams – handles live video data.
