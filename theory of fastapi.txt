Q11. Response Models in FastAPI (Detailed Theory)
 What is a Response Model?

A response model defines the shape/structure of the data your API will return to the client.
It uses Pydantic models to:

Control what fields are returned

Filter out hidden or sensitive fields

Format output

Validate response

Improve API documentation

Ensure consistency across endpoints
How Response Models Work

You pass the model using response_model=ModelName

FastAPI converts your returned data into that model

Any extra fields are removed

Missing fields cause an error
